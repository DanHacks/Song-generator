# Changelog

All notable changes to SautiGen are documented here.

## [0.1.0] - 2026-07-31

### Added
- AI song and instrumental generation from text prompts, lyrics, or audio recordings
- 7 genre styles: afrobeats, gospel, hip-hop, amapiano, ballad, EDM, dancehall
- Stereo 44.1 kHz WAV export with automatic key and tempo detection
- Web recording (WebM) with automatic WAV conversion for melody analysis
- Free plan (5 generations) with Pro and Studio tiers for higher quotas
- Real-time generation progress via streaming API
